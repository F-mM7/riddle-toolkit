# Riddle Toolkit

文字解析・パズルソルバーツール集

## 概要

23個の文字解析・パズル解決ツールを集約したWebアプリケーションです。トップページではツールを5つのジャンルに分けて表示します。

## 収録ツール

### 数える・比べる(4個)

#### 文字カウンター(`char-counter`)

テキストの文字数や文字ごとの出現回数などの統計を表示します。

#### 差集合(`difference-of-character-set`)

2つのテキスト A・B を比較し、文字集合の差分を表示します。

#### 文字ババ抜き(`babanuki`)

入力文字列から、ペアになった文字とペアにならなかった文字を検出します。

#### 単語ベン図(`word-venn`)

最大5つの単語に含まれる文字の重なり方をベン図で表示します。

### 変換する(4個)

#### 文字ずらし(`char-shifter`)

文字を50音順やアルファベット順などのシーケンス上でずらします。個別・一括・比較の3モードがあり、オリジナルシーケンスも使えます。

#### 数字→文字変換(`number-to-char`)

数字を50音順・いろは順・アルファベットの文字に変換します。

#### n文字目抽出(`char-picker`)

文字列から指定した番号の文字を抜き出します。

#### たぬき暗号ソルバー(`tanuki-solver`)

指定した文字列を削除・置換して、たぬき暗号を解きます。途中経過も表示します。

### 並べて見る(4個)

#### 改行グリッド(`line-wrapper`)

文字列を複数の幅で折り返したグリッドを並べ、縦読みを探しやすくします。

#### 回文チェッカー(`palindrome-checker`)

入力したテキストと、それを逆順にしたテキストを並べて表示します。

#### 50音表ビジュアライザー(`kana-visualizer`)

入力したテキストの文字を50音表の上に表示します。

#### 立方体ビジュアライザー(`cube-visualizer`)

展開図に文字を入力し、組み立てた立方体を3Dで回転・転がして確認します。

### 解く・探す(7個)

#### しりとりソルバー(`shiritori-solver`)

入力した単語リストから、しりとりの全解を探します。

#### 回文並べ替え(`palindrome-arranger`)

単語リストを並べ替えて、連結すると回文になる並びを探します。

#### スケルトンソルバー(`skeleton-solver`)

グリッドと単語リストから、スケルトンパズルの解を探します。

#### 単語格子ソルバー(`word-lattice-solver`)

格子点に文字を配置して、全てのセルで単語ができる解を探します。

#### あみだくじソルバー(`amida-solver`)

あみだくじの盤面を作り、上端と下端の文字の対応を求めます。

#### タイリングソルバー(`tiling-solver`)

盤面とピースを入力し、ピースで盤面を敷き詰める解を探します。回転・裏返しの可否を指定できます。

#### 迷路ヘルパー(`maze-helper`)

盤面上で経路をなぞり、曲がり方・線の形・番号の倍数などの条件に合うマスをハイライトします。

### 有名シーケンス(4個)

#### 有名シーケンス一覧(`famous-sequences`)

干支・曜日・月・惑星・春の七草・ドレミのうた・虹の色・方角・四季(いずれも英語)・指の名前(おや・ひとさし…、「ゆび」は付けない)の有名なシーケンスを、要素ごとの読み(かな)や英語の綴りを1列にして縦に1文字ずつ並べた表で一覧表示します(行数は最長の語に合わせ、短い語の下側は空欄)。同じ要素に複数の読み・綴りがあるものは、それぞれの縦書きの表を縦に連結して1つの表にし、境目の罫線を太くしています。曜日(日曜始まり)は読みの下に英語の綴りを、月は和名(むつき…)の下に英語の綴りを、虹の色は訓読み(あか…)の下に音読み(せき・とう…)を並べます。都道府県名と県庁所在地名は、表は出さずにコピーボタンだけのカードにしています。ページ上部の目次(カードのタイトルの一覧)から、各カードへ跳べます。各表の読み・綴りを元の順につなげた文字列をワンクリックでコピーできます。曜日と月の表には、読みをつなげた文字列(「かな」)、英語の3文字略称をつなげた文字列(「英略」)、英語のフル綴りをつなげた文字列(「英フル」)の3つのコピーボタンがあります。虹の色の表には、訓読み(「訓」)と音読み(「音」)の2つのコピーボタンがあります。惑星の表には、略称(水金地火木土天海)の読みをつなげた文字列(「略」、すいきんちかもくどてんかい)と正式名の読みをつなげた文字列(「フル」)の2つのコピーボタンがあります。都道府県名と県庁所在地名のコピーボタン(「かな」)では、ひらがなの名前を地方公共団体コード順(北海道から沖縄。県庁所在地名も同じ都道府県の順)に、1行に1つずつ改行で区切った文字列をコピーします。

#### シーケンスとばし(`sequence-skipper`)

曜日や干支などのシーケンスを、指定した数ずつ送りながら並べます。

#### 都道府県正規表現マッチャー(`prefecture-regex`)

正規表現パターンにマッチする都道府県名・県庁所在地名を探します。

#### 国民の休日一覧(`national-holidays`)

年(1949〜2099年)を入力すると、その年の国民の祝日・振替休日・国民の休日(祝日に挟まれた日)・その年限りの休日(大喪の礼など)を、日付・曜日・名前・読み・種別の表で日付順に表示します。祝日法の改正による祝日の新設・名称変更・日付の変更と、2019〜2021年の特例を反映し、春分の日・秋分の日は計算で求めます。名前と読みを1行に1つずつ改行で区切った文字列をコピーできます。2028年以降は現行法に基づく計算結果で、春分の日・秋分の日は推定です。

## 技術スタック

- React 19.1
- TypeScript
- Vite
- React Router
- CSS Modules
- Three.js(React Three Fiber / drei)

## 開発

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# ビルド
npm run build

# ビルド結果のプレビュー
npm run preview

# Lintチェック
npm run lint

# Lintの自動修正
npm run lint:fix

# 型チェック
npm run typecheck

# フォーマット
npm run format

# フォーマットチェック
npm run format:check
```

## デプロイ

`main`ブランチへpushすると、GitHub Actions(`.github/workflows/deploy.yml`)がビルドし、`dist`をGitHub Pagesへ自動でデプロイします。

手動でデプロイする場合は以下を実行します(`gh-pages`パッケージを使用)。

```bash
npm run deploy
```
